Cold Open A free screenwriting app for Mac that opens and saves Final Draft files

Cold Open writes screenplays with Final Draft's elements and keys, paginates the way Final Draft does, and opens and saves .fdx files, keeping the Final Draft data it doesn't edit. It also reads and writes Fountain.

Download (717 MB) Version 0.1.0 beta 12. macOS 14 Sonoma or later, Apple Silicon. Free, GPL-3.0.

What it does

  • Writes like Final Draft. Tab and Return move through scene headings, action, characters and dialogue. Scene numbers lock and take A-numbers, revisions get their page colors, and script notes and breakdown tags survive a trip through FDX.
  • Templates for the format you're in. Features, one-hour drama, half-hour single-camera, multi-camera and stage plays, with act breaks and page breaks where those formats put them.
  • Write together. Co-writers on the same network, or through a relay, type in the same script at once and see each other's cursors.
  • Dictate scenes. The default speech recognizer is included and works offline. Dictate rough text, then use Format Draft to make screenplay elements after its one-time local model setup.
  • Hear the table read. Download local voices and Cold Open reads the script with a cast picked from what the script says about each character.
  • AI only if you want it. Proofreading suggestions, an assistant that reads the whole script before it answers and proposes edits you approve, casting help and an optional sentence completion that stays off until you turn it on. It runs on a local Ollama model, your own API key, or your ChatGPT plan, and nothing changes in the script until you accept it.
  • Use your ChatGPT plan. Sign in with ChatGPT and Cold Open's AI features use your ChatGPT plan. Cold Open itself is free. Learn more

Questions

Is Cold Open free?

Yes. It is free and open source under GPL-3.0. The AI features are optional and run on a local model, your own API key or your ChatGPT plan.

Can it open my Final Draft scripts?

Yes. It opens and saves .fdx files and keeps the Final Draft data it doesn't edit, so a script can go back to Final Draft afterwards. It reads and writes Fountain as well.

Does it run on Intel Macs or Windows?

No. Cold Open needs an Apple Silicon Mac with macOS 14 Sonoma or later.

Download Cold Open 0.1.0 beta 12, 717 MB disk image

Open the disk image and drag Cold Open to Applications. Needs an Apple Silicon Mac with macOS 14 Sonoma or later; local table-read voices need macOS 15.

Or install with Homebrew

brew tap MIM18-code/cold-open
brew trust MIM18-code/cold-open
brew install --cask cold-open

Homebrew asks you to trust a third-party tap once, which is the second line. Update later with brew upgrade --cask cold-open.
