Cold Open A free screenwriting app for Mac that opens and saves Final Draft files

Cold Open writes screenplays with Final Draft's elements and keys, paginates the way Final Draft does, and opens and saves .fdx files, keeping the Final Draft data it doesn't edit. It also reads and writes Fountain.

What it does

Final Draft keys and pages
Tab and Return move through scene headings, action, characters and dialogue. Scene numbers lock and take A-numbers, revisions get their page colors, and script notes and breakdown tags survive a trip through FDX.
Templates
Features, one-hour drama, half-hour single-camera, multi-camera and stage plays, with act breaks and page breaks where those formats put them.
Co-writing
Co-writers on the same network, or through a relay, type in the same script at once and see each other's cursors.
Dictation
The speech recognizer is included and works offline. Dictate rough text, then use Format Draft to turn it into screenplay elements. Format Draft needs a one-time local model setup.
Table read
Download local voices and Cold Open reads the script aloud, with a cast picked from what the script says about each character.
AI, if you turn it on
Proofreading suggestions, an assistant that reads the whole script before it answers and proposes edits you approve, casting help, and sentence completion that stays off until you switch it on. These run on a local Ollama model, your own API key or your ChatGPT plan, and nothing changes in the script until you accept it. Questions

Is Cold Open free?

Yes. It is free and open source under GPL-3.0. The AI features are optional and run on a local model, your own API key or your ChatGPT plan.

Can it open my Final Draft scripts?

Yes. It opens and saves .fdx files and keeps the Final Draft data it doesn't edit, so a script can go back to Final Draft afterwards. It reads and writes Fountain as well.

Why is the download so large?

Most of it is the speech recognition model that lets dictation work offline. The app is built on Electron, which accounts for most of the rest.

Does it run on Intel Macs or Windows?

No. Cold Open needs an Apple Silicon Mac with macOS 14 Sonoma or later.

Install

Open the disk image and drag Cold Open to Applications. Needs an Apple Silicon Mac with macOS 14 Sonoma or later; local table-read voices need macOS 15.
