Reports and sides

Reports

Tools > Reports… opens the report window with nine reports:

  1. Characters: speeches, dialogue words, scenes, first and last scenes, first and last page, pages.
  2. Scenes: lengths, cast per scene.
  3. Locations: every distinct location, grouped.
  4. Statistics: pages and words overall.
  5. Dialogue: complete speeches, extensions and parentheticals per character.
  6. Notes: every note with status.
  7. Elements: counts by element type.
  8. Scene cast: who appears in each scene with their speeches.
  9. Tags by scene, and Tags by tag: your breakdown tags.

A header line summarizes: "3 pages, 6 scenes, 355 words". Export CSV…, Text… and Print / PDF… export what the report shows. The visible columns, column widths, sort and print layout all match what the view is showing. Every report keeps its own state, so returning to the window restores your sort; the highlighted row links back to its scenes in the script.

Report presets save a column set and print layout. Paper is US Letter or A4, orientation per report, with repeated headings and a reading layout for screen.

Where production counts live

Cold Open's reports are script reports. Availability, day breaks, day out of days and the production schedule stay in Backlot; see Handoff to Backlot.

Actor sides

File > Export Sides… exports scenes for actors to read at rehearsal:

  1. Choose the scenes with the checkboxes; Select all and Select none set the range. Scenes with dialogue are listed; add scenes by hand for cast who appear without speaking. There is no claimed automatic silent-character inference.
  2. Choose Final Draft (.fdx) or Fountain (.fountain) format.
  3. Choose Export… and save.

For PDF sides in screenplay layout, use File > Delivery PDF, Watermarks and Actor Sides…, described in Exports under delivery PDFs.
