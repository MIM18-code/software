Video walkthroughs

These recordings use fictional Night Ferry material in the running app, in light mode at 1440x900. Each H.264 MP4 has burned captions and no audio. The SRT provides separate captions. The narration files are macOS say drafts, timed to the caption cues, for reviewing the wording before a final voice recording.

The first-launch walkthrough starts with empty app data and no configured script or budget engines. It uses manual scene entry, shows a failed import and the preserved scene, and explains that AI is optional. The native folder and file choices were supplied by the recording harness. The separate import and production examples below use a preconfigured demonstration environment and do not prove that import works on a fresh installation.

The import example uses a scripted native file choice and confirms a real tagged-FDX import. It shows absent-scene choices during reconciliation; review those choices before confirming your own import. The call-sheet example covers drafting and preview. It sends nothing to recipients.

Captured on November 2, 2026. The downloadable Fountain and tagged FDX samples contain six scenes. Backlot screenshots use a separate demonstration project with additional fictional scenes.

Your first Backlot project

Captions are visible in the video. Download video

Read the captions

A fresh install opens Projects with no project yet. The yellow notice reports missing import and export components.

Choose New project, then Choose folder. Select a parent folder for the project.

Enter a title, keep the generated project file, and leave optional files blank.

With Non-union selected for this fictional example, choose Create.

The empty project opens on the stripboard. Choose Breakdown to add a scene.

Choose Add scene. Enter scene 1, INT. KITCHEN - DAY, and 8 eighths for one page.

Choose Create. The manually entered scene appears in Breakdown.

On Stripboard, the new scene starts in the unscheduled column.

Import FDX currently requires the missing script engine. We will try the sample and show the result.

Dismiss the error. The manual scene remains; add scenes by hand while import is unavailable.

AI is optional. The project, manual breakdown, and board work without signing in or downloading a model.
