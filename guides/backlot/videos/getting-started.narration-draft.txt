Your first Backlot project: step-by-step screens.

Step-by-step screens: start on Projects and choose New project.

Choose a folder, enter a title, and keep or change the project file path.

Leave optional technical fields blank to create an empty project.

In Breakdown, add a scene manually if you want to start without a script.

Or choose Import FDX and select a Final Draft or Fountain screenplay.

The bundled reader imports scenes. This screen shows the imported sample.

Select an imported scene and use Read scene to check its screenplay text.

AI is optional. Beta 8 needs no external script reader or Chrome for import.
