# Video walkthroughs

These walkthroughs use fictional Night Ferry material from the running app, in light mode at 1440x900. The beta 8 first-launch walkthrough uses step-by-step screenshots; the other clips are screen recordings. Each H.264 MP4 has burned captions and no audio. The SRT provides separate captions. The narration files are macOS `say` drafts, timed to the caption cues, for reviewing the wording before a final voice recording.

The beta 8 first-launch walkthrough starts with empty app data and no configured script or budget engines. It creates a project, imports a screenplay with the included reader and explains that AI is optional. The native folder and file choices were supplied by the recording harness. The other production examples use a preconfigured fictional demonstration project.

The import example uses a scripted native file choice and confirms a real tagged-FDX import. It shows absent-scene choices during reconciliation; review those choices before confirming your own import. The call-sheet example covers drafting and preview. It sends nothing to recipients.

Captured on November 2, 2026; the first-launch walkthrough was refreshed for beta 8. The downloadable [Fountain](../sample/Night-Ferry.fountain) and [tagged FDX](../sample/Night-Ferry-tagged.fdx) samples contain six scenes. Backlot screenshots use a separate demonstration project with additional fictional scenes.
