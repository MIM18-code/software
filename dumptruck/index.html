Dumptruck Free camera card offload for Mac that checks every copy

Dumptruck copies a camera card to your backup drives, reads each copy back off the drive to check it against the card, and writes an HTML and PDF report with ASC MHL manifests. A card shows SAFE TO CLEAR only when two separate drives hold verified copies. There is no erase button. Wiping the card is still your call.

Version 0.6.1 beta. macOS 14 Sonoma or later, Apple Silicon. Free, Apache-2.0. Other ways to install

SAFE TO CLEAR means the job passed Dumptruck's verification when it ran. It can't protect you from a drive that fails later. Dumptruck is still a beta, so keep your usual backup routine alongside it, and read the report before you erase a card.

What it does

Verification
Copies are written past the macOS file cache, so the verify pass reads the data back from the drive itself instead of from memory.
Cards that come back
Bring back a card that wasn't formatted and Dumptruck copies only the new clips into the same folder, adding a new manifest generation.
Several cards
Drag several cards over and Start Offload copies every one that is ready, all at once or one at a time. A card that can't start stays in the list with the reason.
Pause and resume
Pause holds a transfer where it is, and Resume carries on from the same place with nothing copied twice. Pull the wrong card or kill the power and the next run picks up what is already verified.
Single clips
Pick the clips you want with Choose Source Files…, or drag them in from Finder, and Dumptruck copies just those, straight from the drive. They finish as VERIFIED, not SAFE TO CLEAR, since the rest of the drive wasn't copied.
Reports
Every offload gets an HTML and PDF report with clip thumbnails and metadata, a JSON receipt, ASC MHL v2.0 and legacy MHL v1.1.
Camera formats
Dumptruck reads R3D, BRAW and ARRIRAW files for metadata and thumbnails through bundled helpers, which ask you to accept their terms the first time. Copying and verification work either way.

Questions

How does it check a copy?

It hashes each file as it reads the card, then reads every copy back from the destination drive and compares. The copies are written past the macOS file cache, so that read comes from the drive and not from memory.

When does a card show SAFE TO CLEAR?

Only when two separate physical drives hold verified copies and the card itself read the same twice. Two partitions on one disk count as one drive. One verified drive shows VERIFIED and tells you to keep the card.

What does it write besides the copies?

An HTML and PDF report with clip thumbnails, a JSON receipt, and ASC MHL v2.0 and legacy MHL v1.1 manifests.

Install

Open the disk image and drag Dumptruck to Applications. Needs an Apple Silicon Mac with macOS 14 Sonoma or later.
